# חסידות גור

אפליקציית ווב (PWA) חד-עמודית לקהילת חסידות גור, הכוללת:

- **זמני תפילות** — ימי חול, ערב שבת, שבת קודש וראש חודש
- **שעות קבלת קהל** — של הרב, הגבאים והועד
- **אלפון** — עם חיפוש חופשי וסינון לפי קטגוריה
- **חדשות** — עדכוני הקהילה, מהחדש לישן

האפליקציה היא קבצים סטטיים בלבד (HTML/CSS/JS), ללא שרת או תהליך build,
וניתנת להתקנה כאפליקציה במסך הבית (PWA), כולל שימוש במצב לא מקוון.

## הרצה מקומית

```bash
npx serve .
```

או פשוט לפתוח את `index.html` בדפדפן.

## עריכת התוכן

כל התוכן המוצג באפליקציה (זמני תפילות, קבלת קהל, אנשי קשר וחדשות) נמצא
במקום אחד — בראש הקובץ `app.js`, באובייקט בשם `DATA`. כדי לעדכן תוכן:

1. פתחו את `app.js`.
2. ערכו את הערכים המתאימים תחת `tefillos` / `kabbalasKahal` / `phonebook` / `news`.
3. שמרו — אין צורך בשום פעולה נוספת.

התוכן שקיים כרגע הוא **תוכן לדוגמה** ויש להחליפו בפרטים האמיתיים של הקהילה
(שמות, שעות, מספרי טלפון) לפני פרסום האפליקציה.

## פריסה (Deploy)

מכיוון שמדובר בקבצים סטטיים, ניתן לפרוס את האפליקציה בקלות בכל שירות אחסון
סטטי, למשל Vercel, Netlify, GitHub Pages או Firebase Hosting.
